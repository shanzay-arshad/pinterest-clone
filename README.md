
# Pinterest Clone

A beginner-friendly image-sharing platform inspired by Pinterest.

## Technology Stack

- Frontend: HTML, CSS, Bootstrap 5, JavaScript
- Backend: Python, FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Image Storage: Local Storage (Amazon S3 planned)
- Containerization: Docker

## Planned Features

- User registration and login
- Explore image feed
- Upload images (Pins)
- View pin details
- User profiles
- Like and unlike pins
- Boards and search (future improvements)
